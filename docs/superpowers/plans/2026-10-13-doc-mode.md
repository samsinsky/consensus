# Doc Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a doc thread type: one document that participants review in parallel rounds, proposing anchored changes with reasons in margin cards that the user accepts, rejects, edits, or replies to, while editing the document live.

**Architecture:** The server keeps doc state inside the thread JSON (`thread.kind = 'doc'`, `thread.doc`). A new `DocService` runs rounds through a `Router.runTurn` extracted from the chat path, composes round messages, parses each answer's JSON block, and anchors proposals by quote against the round snapshot. The client edits Markdown in TipTap, re-anchors proposals against the live editor text with the same shared anchoring module, draws them as ProseMirror decorations, and lays out margin cards beside their text.

**Tech Stack:** Node 24, TypeScript (ESM, NodeNext, `.js` import suffixes), React 19, Vite 8, Vitest 5 with jsdom, TipTap 3.32 (`@tiptap/react`, `@tiptap/core`, `@tiptap/pm`, `@tiptap/starter-kit`, `@tiptap/markdown`), `marked` 18 for server-side Markdown to plain text.

**Spec:** `docs/superpowers/specs/2026-10-13-doc-mode-design.md` (builds on `docs/superpowers/specs/2026-10-05-consensus-design.md`).

## Global Constraints

- Participants never learn which provider wrote a proposal or reply: label `by="you"` or `by="another reviewer"`, replies "You", "Another reviewer", "Me".
- One round at a time per thread; a doc thread never accepts chat sends.
- A stopped or failed turn never advances a participant's session (existing `runTurn` rule).
- Quotes match after straightening curly quotes and collapsing whitespace; a proposal must match the round snapshot exactly once.
- Context stored with a proposal: up to 32 characters each side (`CONTEXT = 32`).
- Formatting: paragraphs, headings, bold, italic, bulleted and numbered lists, links. No toolbar.
- Copy writes `text/html` with a `text/plain` fallback.
- UI copy follows the spec's wording exactly: "N versions", "Your call", "Text changed", "Dismiss", "Reject all", "N resolved", "Not saved", "Copied", "Ask for review:", "+ Add participant", "+ N more".
- Server endpoints keep the existing Host, Origin and JSON content-type checks (no change needed: they apply to every route).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Test command for every task: `npx vitest run` (whole suite) plus `npm run typecheck`.

## Review Focus

- A model quotes text with Markdown marks (`**gone deep on**`) or curly quotes: the user expects it to match the plain document text, not be dropped. Test: Task 1 `cleanQuote` cases.
- The user types, then restores a snapshot within the autosave delay: the queued save must not overwrite the restored text. Test: Task 4 "refuses a save from an older revision".
- The user edits text a proposal quotes while a round runs: the proposal shows "Text changed", it never anchors to the wrong place. Test: Task 8 "an edited quote no longer anchors".
- Accepting a replacement that contains `**bold**`, `*italic*` or a link: the document gets formatting, not literal asterisks. Test: Task 8 `inlineMarkdown` cases.
- Deleting a doc thread mid-round: the round stops and nothing writes the thread back. Test: Task 5 "deleting the thread stops the round".

```ts
/** Plain text with, for each character, its position in the source it came from. */
export type TextIndex = { text: string; map: number[] };

export type Anchor = { quote: string; prefix: string; suffix: string };

/** Characters of context stored on each side of a quote. */
export const CONTEXT = 32;

const STRAIGHT: Record<string, string> = {
  '‘': "'", '’': "'", '‚': "'", '‛': "'",
  '“': '"', '”': '"', '„': '"', ' ': ' ',
};

/** Straightens quotes and collapses whitespace runs to one space, keeping each character's source position. */
export function buildIndex(chars: Iterable<{ ch: string; pos: number }>): TextIndex {
  let text = '';
  const map: number[] = [];
  let lastWasSpace = true;
  for (const { ch, pos } of chars) {
    const c = STRAIGHT[ch] ?? ch;
    if (/\s/.test(c)) {
      if (!lastWasSpace) {
        text += ' ';
        map.push(pos);
        lastWasSpace = true;
      }
      continue;
    }
    text += c;
    map.push(pos);
    lastWasSpace = false;
  }
  if (text.endsWith(' ')) {
    text = text.slice(0, -1);
    map.pop();
  }
  return { text, map };
}

export function indexString(s: string): TextIndex {
  const chars: { ch: string; pos: number }[] = [];
  for (let i = 0; i < s.length; i++) chars.push({ ch: s[i], pos: i });
  return buildIndex(chars);
}

export function normalize(s: string): string {
  return indexString(s).text;
}

/** A model's quote as plain words: Markdown marks, link targets, and line markers removed. */
export function cleanQuote(s: string): string {
  return s
    .replace(/\[([^\]]*)\]\([^)]*\)/g, '$1')
    .replace(/^\s*(#{1,6}\s+|[-*+]\s+|\d+[.)]\s+|>\s*)/gm, '')
    .replace(/\*\*|__|`/g, '')
    .replace(/(^|[^\w*])\*(?=\S)|(?<=\S)\*(?=[^\w*]|$)/g, '$1');
}

export function findAll(index: TextIndex, quote: string): number[] {
  const q = normalize(cleanQuote(quote));
  if (!q) return [];
  const out: number[] = [];
  for (let i = index.text.indexOf(q); i >= 0; i = index.text.indexOf(q, i + 1)) out.push(i);
  return out;
}

export function contextAt(index: TextIndex, start: number, length: number): { prefix: string; suffix: string } {
  return {
    prefix: index.text.slice(Math.max(0, start - CONTEXT), start),
    suffix: index.text.slice(start + length, start + length + CONTEXT),
  };
}

/** Where an anchor sits now: its only match, else the match whose surroundings fit best, else undefined. */
export function locate(index: TextIndex, anchor: Anchor): { start: number; end: number } | undefined {
  const hits = findAll(index, anchor.quote);
  if (!hits.length) return undefined;
  const length = normalize(cleanQuote(anchor.quote)).length;
  let best = hits[0];
  let bestScore = -1;
  if (hits.length > 1) {
    for (const h of hits) {
      const ctx = contextAt(index, h, length);
      const score = sharedEnd(ctx.prefix, anchor.prefix) + sharedStart(ctx.suffix, anchor.suffix);
      if (score > bestScore) {
        best = h;
        bestScore = score;
      }
    }
  }
  return { start: best, end: best + length };
}

export function toSource(index: TextIndex, range: { start: number; end: number }): { from: number; to: number } {
  return { from: index.map[range.start], to: index.map[range.end - 1] + 1 };
}

function sharedStart(a: string, b: string): number {
  let i = 0;
  while (i < a.length && i < b.length && a[i] === b[i]) i++;
  return i;
}

function sharedEnd(a: string, b: string): number {
  let i = 0;
  while (i < a.length && i < b.length && a[a.length - 1 - i] === b[b.length - 1 - i]) i++;
  return i;
}
```

import { marked } from 'marked';

const ENTITIES: Record<string, string> = { amp: '&', lt: '<', gt: '>', quot: '"', apos: "'", nbsp: ' ' };

/** The plain words of a Markdown document as the editor shows them: no marks, one block per line. */
export function markdownToPlain(md: string): string {
  const html = marked.parse(md, { async: false }) as string;
  const text = html
    .replace(/<\/(p|h[1-6]|li|blockquote|pre)>|<br\s*\/?>/gi, '\n')
    .replace(/<[^>]+>/g, '');
  return decode(text).trim();
}

function decode(s: string): string {
  return s.replace(/&(#\d+|#x[0-9a-f]+|[a-z]+);/gi, (whole, e: string) => {
    if (e[0] === '#') return String.fromCodePoint(e[1] === 'x' || e[1] === 'X' ? parseInt(e.slice(2), 16) : Number(e.slice(1)));
    return ENTITIES[e.toLowerCase()] ?? whole;
  });
}

import type { Proposal, ProposalStatus, Stance } from './types.js';

export const RESOLVED: ProposalStatus[] = ['accepted', 'rejected', 'not_chosen', 'dismissed'];

/** Ids of ranges that overlap, grouped in text order. Ranges that only touch stay apart. */
export function groupOverlaps(ranges: { id: string; start: number; end: number }[]): string[][] {
  const sorted = [...ranges].sort((a, b) => a.start - b.start || a.id.localeCompare(b.id, undefined, { numeric: true }));
  const groups: string[][] = [];
  let end = -Infinity;
  for (const r of sorted) {
    if (groups.length && r.start < end) {
      groups.at(-1)!.push(r.id);
      end = Math.max(end, r.end);
    } else {
      groups.push([r.id]);
      end = r.end;
    }
  }
  return groups;
}

/** Each participant's latest stance on a proposal. */
export function stances(p: Proposal): Map<string, Stance> {
  const out = new Map<string, Stance>();
  for (const r of p.replies) if (r.from !== 'user' && r.stance) out.set(r.from, r.stance);
  return out;
}

export function stanceCounts(p: Proposal): { agree: number; disagree: number } {
  let agree = p.authors.length;
  let disagree = 0;
  for (const [from, s] of stances(p)) {
    if (p.authors.includes(from)) continue;
    if (s === 'agree') agree++;
    if (s === 'disagree') disagree++;
  }
  return { agree, disagree };
}

export function isYourCall(group: Proposal[]): boolean {
  return group.some((p) => [...stances(p).values()].includes('your_call'));
}

```ts
  /** Runs one CLI turn. Memory advances only when the turn finishes. */
  async runTurn(p: Participant, message: string, images: ImageInput[], signal: AbortSignal, hooks: TurnHooks = {}): Promise<TurnResult> {
    const adapter = this.deps.adapters[p.provider];
    let pendingSession: string | undefined;
    let text = '';
    const sources: string[] = [];
    let result: TurnResult | undefined;
    try {
      for await (const ev of adapter.send({
        sessionId: p.sessionId, message, model: p.model, effort: p.effort,
        promptHash: p.promptHash, promptPath: snapshotPath(this.deps.paths, p.promptHash),
        images: images.length ? images : undefined,
        signal,
      })) {
        if (ev.type === 'session') {
          pendingSession = ev.sessionId;
        } else if (ev.type === 'delta') {
          text += ev.text;
          hooks.onDelta?.(ev.text);
        } else if (ev.type === 'activity') {
          hooks.onActivity?.(ev.text);
        } else if (ev.type === 'source') {
          if (!sources.includes(ev.url)) {
            sources.push(ev.url);
            hooks.onSource?.(ev.url);
          }
        } else if (ev.type === 'warning') {
          console.warn(`consensus: ${p.provider}: ${ev.message}`);
        } else if (ev.type === 'done') {
          // Only a finished turn advances memory; stopped or failed forks are dropped.
          if (pendingSession) p.sessionId = pendingSession;
          result = { status: 'done', text: ev.text, sources };
        } else if (ev.type === 'error') {
          result = { status: 'error', text, error: ev.error, sources };
        }
      }
    } catch (e) {
      result = { status: 'error', text, error: { code: 'unknown', message: e instanceof Error ? e.message : String(e) }, sources };
    }
    if (result) return result;
    if (signal.aborted) return { status: 'stopped', text, sources };
    return { status: 'error', text, error: { code: 'unknown', message: 'The CLI ended without a reply.' }, sources };
  }

  private async run(thread: Thread, p: Participant, reply: ReplyMessage, message: string, images: ImageInput[], controller: AbortController): Promise<void> {
    const result = await this.runTurn(p, message, images, controller.signal, {
      onDelta: (text) => {
        reply.text += text;
        this.deps.hub.emit(thread.id, { type: 'delta', messageId: reply.id, text });
      },
      onActivity: (text) => this.deps.hub.emit(thread.id, { type: 'activity', messageId: reply.id, text }),
      onSource: (url) => {
        reply.sources = [...(reply.sources ?? []), url];
        this.deps.hub.emit(thread.id, { type: 'thread', thread });
      },
    });
    reply.status = result.status;
    if (result.status === 'done') reply.text = result.text;
    if (result.error) reply.error = result.error;
    this.busy.delete(p.id);
    this.inflight.delete(reply.id);
    try {
      await this.commit(thread);
    } catch (e) {
      console.error('consensus: could not save the finished reply', e);
    }
  }
```

Note: the loop never returns early. Returning from `for await` would close the CLI's iterator before it exits, which the existing `run` deliberately avoids.

```ts
import type { DocState, Proposal, ProposalReply } from '../shared/types.js';

export const ROUND_TASK =
  'What to do:\n' +
  '1. Propose changes only to fix real problems: errors, unclear writing, or anything that misses the brief. If a change comes down to taste, leave it.\n' +
  '2. Reply to each open proposal you didn\'t write: agree, disagree with a reason, or "your call" when it comes down to taste.\n' +
  '3. Leave one short note on the whole draft: structure, direction, and anything line edits would miss.\n' +
  "4. Don't rewrite the whole document.\n\n" +
  'End your answer with one JSON block in exactly this shape:\n' +
  '```json\n' +
  '{\n' +
  '  "proposals": [{ "quote": "exact words from the document", "replacement": "new words", "reason": "one or two sentences" }],\n' +
  '  "replies": [{ "proposal": "P4", "stance": "agree" | "disagree" | "your_call", "text": "one or two sentences" }],\n' +
  '  "note": "your note on the whole draft"\n' +
  '}\n' +
  '```\n' +
  'For "quote", copy the exact words from the document without formatting marks, long enough to appear only once. ' +
  'To delete text, use an empty replacement. To add text, quote the words it follows and include them in the replacement.';

export type RoundInput = {
  doc: DocState;
  round: number;
  receiver: string;
  /** Brief attachments, already rendered. */
  briefBlocks: string[];
  /** When the receiver's previous round was sent; absent on its first review. */
  since?: string;
};

const STANCE_LABEL = { agree: 'agree', disagree: 'disagree', your_call: 'your call' } as const;

export function composeRound({ doc, round, receiver, briefBlocks, since }: RoundInput): string {
  const blocks = [
    `Brief:\n<brief>\n${doc.brief.trim()}\n</brief>`,
    ...briefBlocks,
    `Document (round ${round}):\n<document>\n${doc.markdown}\n</document>`,
  ];
  const open = doc.proposals.filter((p) => p.status === 'open');
  if (open.length) blocks.push(`Open proposals:\n${open.map((p) => proposalBlock(p, receiver)).join('\n')}`);
  const rejected = doc.proposals.filter(
    (p) => (p.status === 'rejected' || p.status === 'not_chosen') && !!p.resolvedAt && (!since || p.resolvedAt > since),
  );
  if (rejected.length) blocks.push(`Rejected since your last review:\n${rejected.map(rejectedLine).join('\n')}`);
  blocks.push(ROUND_TASK);
  return blocks.join('\n\n');
}

export function repairMessage(reason: string): string {
  return `Your answer ${reason}. Reply with only the JSON block.`;
}

function proposalBlock(p: Proposal, receiver: string): string {
  const by = p.authors.includes(receiver) ? 'you' : 'another reviewer';
  const lines = [`<proposal id="${p.id}" by="${by}">`, `Replace: "${p.quote}"`, `With: "${p.replacement}"`, `Reason: ${p.reason}`];
  if (p.replies.length) {
    lines.push('Replies:');
    for (const r of p.replies) lines.push(`- ${speaker(r, receiver)}${r.stance ? ` (${STANCE_LABEL[r.stance]})` : ''}: ${r.text}`);
  }
  lines.push('</proposal>');
  return lines.join('\n');
}

function speaker(r: ProposalReply, receiver: string): string {
  if (r.from === 'user') return 'Me';
  return r.from === receiver ? 'You' : 'Another reviewer';
}

function rejectedLine(p: Proposal): string {
  const mine = [...p.replies].reverse().find((r) => r.from === 'user');
  return `- ${p.id}: "${p.quote}" → "${p.replacement}"${mine ? ` (my reply: ${mine.text})` : ''}`;
}
```

```ts
import type { Stance } from '../shared/types.js';

export type ParsedAnswer = {
  proposals: { quote: string; replacement: string; reason: string }[];
  replies: { proposal: string; stance: Stance; text: string }[];
  note: string;
};

/** On failure, reason completes "Your answer …". */
export type ParseResult = { ok: true; value: ParsedAnswer } | { ok: false; reason: string };

const STANCES: Stance[] = ['agree', 'disagree', 'your_call'];

export function parseAnswer(text: string, knownIds: Set<string>): ParseResult {
  const raw = lastJson(text);
  if (raw === undefined) return { ok: false, reason: 'was missing the JSON block' };
  let data: unknown;
  try {
    data = JSON.parse(raw);
  } catch (e) {
    return { ok: false, reason: `had a JSON block that failed: ${(e as Error).message}` };
  }
  return validate(data, knownIds);
}

function lastJson(text: string): string | undefined {
  const fenced = [...text.matchAll(/```json[^\n]*\n([\s\S]*?)```/g)];
  if (fenced.length) return fenced.at(-1)![1];
  // No fence: take the last balanced {...} that parses.
  for (let end = text.lastIndexOf('}'); end >= 0; end = text.lastIndexOf('}', end - 1)) {
    let depth = 0;
    for (let i = end; i >= 0; i--) {
      if (text[i] === '}') depth++;
      else if (text[i] === '{' && --depth === 0) {
        const candidate = text.slice(i, end + 1);
        try {
          JSON.parse(candidate);
          return candidate;
        } catch {
          break;
        }
      }
    }
  }
  return undefined;
}

function validate(data: unknown, knownIds: Set<string>): ParseResult {
  const fail = (reason: string): ParseResult => ({ ok: false, reason });
  if (!isObject(data)) return fail('had a JSON block that is not an object');
  const value: ParsedAnswer = { proposals: [], replies: [], note: '' };

  const proposals = data.proposals ?? [];
  if (!Array.isArray(proposals)) return fail('had "proposals" that is not a list');
  for (const p of proposals) {
    if (!isObject(p) || typeof p.quote !== 'string' || typeof p.replacement !== 'string' || typeof p.reason !== 'string') {
      return fail('had a proposal without "quote", "replacement" and "reason" text');
    }
    if (!p.quote.trim()) return fail('had a proposal with an empty "quote"');
    value.proposals.push({ quote: p.quote, replacement: p.replacement, reason: p.reason });
  }

  const replies = data.replies ?? [];
  if (!Array.isArray(replies)) return fail('had "replies" that is not a list');
  for (const r of replies) {
    if (!isObject(r) || typeof r.proposal !== 'string' || typeof r.text !== 'string') return fail('had a reply without "proposal" and "text"');
    if (!STANCES.includes(r.stance as Stance)) return fail('had a reply with a stance other than "agree", "disagree" or "your_call"');
    // A reply to a proposal the model invented or misremembered is dropped, not fatal.
    if (knownIds.has(r.proposal)) value.replies.push({ proposal: r.proposal, stance: r.stance as Stance, text: r.text });
  }

  if (data.note !== undefined && typeof data.note !== 'string') return fail('had a "note" that is not text');
  value.note = (data.note as string | undefined) ?? '';
  return { ok: true, value };
}

function isObject(v: unknown): v is Record<string, unknown> {
  return typeof v === 'object' && v !== null && !Array.isArray(v);
}

```ts
import type { DocState, Thread } from '../shared/types.js';
import { deriveTitle, RouterError, UNTITLED, type Router } from './router.js';

export function emptyDoc(input: { brief?: string; markdown?: string } = {}): DocState {
  return {
    brief: input.brief ?? '',
    markdown: input.markdown ?? '',
    savedAt: new Date().toISOString(),
    revision: 0,
    included: [],
    rounds: [],
    proposals: [],
    nextProposal: 1,
  };
}

export class DocService {
  constructor(protected router: Router) {}

  async create(input: { brief?: string; markdown?: string } = {}): Promise<Thread> {
    const thread = await this.router.createThread();
    thread.kind = 'doc';
    thread.doc = emptyDoc(input);
    if (input.brief?.trim()) thread.title = deriveTitle(input.brief, []);
    await this.router.save(thread);
    return thread;
  }

  async openAsDoc(threadId: string, replyId: string): Promise<Thread> {
    const source = await this.router.getThread(threadId);
    if (!source) throw new RouterError('not_found', 'That thread does not exist.');
    const reply = source.messages.find((m) => m.id === replyId && m.kind === 'reply');
    if (!reply || reply.kind !== 'reply' || reply.status !== 'done') throw new RouterError('not_found', 'That reply is not finished or no longer exists.');
    const first = source.messages.find((m) => m.kind === 'user' && m.text.trim());
    const thread = await this.create({ brief: first?.kind === 'user' ? first.text : '', markdown: reply.text });
    if (source.title !== UNTITLED) thread.title = source.title;
    // Fresh sessions: a doc never shares a CLI conversation with a chat thread.
    for (const p of source.participants) {
      await this.router.addParticipant(thread.id, { provider: p.provider, model: p.model, effort: p.effort });
    }
    await this.router.save(thread);
    return thread;
  }

  async saveDoc(threadId: string, input: { revision: number; markdown?: string; brief?: string; briefAttachmentIds?: string[] }): Promise<void> {
    const thread = await this.mustDoc(threadId);
    const doc = thread.doc;
    if (input.revision !== doc.revision) throw new RouterError('busy', 'The document changed on the server. Reload to keep editing.');
    if (input.briefAttachmentIds) doc.briefAttachments = await this.router.resolveAttachments(thread.id, input.briefAttachmentIds);
    if (input.markdown !== undefined) doc.markdown = input.markdown;
    if (input.brief !== undefined) {
      doc.brief = input.brief;
      if (thread.title === UNTITLED && input.brief.trim()) thread.title = deriveTitle(input.brief, []);
    }
    doc.savedAt = new Date().toISOString();
    await this.router.save(thread);
  }

  async setIncluded(threadId: string, participantId: string, included: boolean): Promise<void> {
    const thread = await this.mustDoc(threadId);
    if (!thread.participants.some((p) => p.id === participantId)) throw new RouterError('not_found', 'That participant does not exist.');
    const rest = thread.doc.included.filter((id) => id !== participantId);
    thread.doc.included = included ? [...rest, participantId] : rest;
    await this.router.save(thread);
  }

  async updateProposal(
    threadId: string,
    proposalId: string,
    input: { status?: 'accepted' | 'rejected' | 'dismissed'; replacement?: string; notChosen?: string[] },
  ): Promise<void> {
    const thread = await this.mustDoc(threadId);
    const p = thread.doc.proposals.find((x) => x.id === proposalId);
    if (!p) throw new RouterError('not_found', 'That proposal no longer exists.');
    if (p.status !== 'open') throw new RouterError('invalid', 'That proposal is already settled.');
    const now = new Date().toISOString();
    if (input.replacement !== undefined) p.replacement = input.replacement;
    if (input.status) {
      p.status = input.status;
      p.resolvedAt = now;
    }
    for (const id of input.notChosen ?? []) {
      const other = thread.doc.proposals.find((x) => x.id === id);
      if (other?.status === 'open') {
        other.status = 'not_chosen';
        other.resolvedAt = now;
      }
    }
    await this.router.save(thread);
  }

  async reply(threadId: string, proposalId: string, text: string): Promise<void> {
    const thread = await this.mustDoc(threadId);
    const p = thread.doc.proposals.find((x) => x.id === proposalId);
    if (!p) throw new RouterError('not_found', 'That proposal no longer exists.');
    if (!text.trim()) throw new RouterError('invalid', 'Write a reply first.');
    p.replies.push({ from: 'user', text: text.trim(), at: new Date().toISOString() });
    await this.router.save(thread);
  }

  async restore(threadId: string, round: number): Promise<void> {
    const thread = await this.mustDoc(threadId);
    const r = thread.doc.rounds.find((x) => x.n === round);
    if (!r) throw new RouterError('not_found', 'That round does not exist.');
    thread.doc.markdown = r.snapshot;
    thread.doc.revision++;
    thread.doc.savedAt = new Date().toISOString();
    await this.router.save(thread);
  }

  protected async mustDoc(threadId: string): Promise<Thread & { doc: DocState }> {
    const thread = await this.router.getThread(threadId);
    if (!thread) throw new RouterError('not_found', 'That thread does not exist.');
    if (thread.kind !== 'doc' || !thread.doc) throw new RouterError('invalid', 'This thread is not a doc.');
    return thread as Thread & { doc: DocState };
  }
}

```ts
/** Adds a participant's answer to the doc. Returns proposals whose quote failed to match the snapshot exactly once. */
export function ingest(doc: DocState, author: string, round: Round, answer: ParsedAnswer, now: string): { quote: string; reason: string }[] {
  const index = indexString(markdownToPlain(round.snapshot));
  const rejected: { quote: string; reason: string }[] = [];
  for (const prop of answer.proposals) {
    const hits = findAll(index, prop.quote);
    if (hits.length !== 1) {
      rejected.push({ quote: prop.quote, reason: hits.length ? `matched ${hits.length} places` : 'not found' });
      continue;
    }
    const quote = normalize(cleanQuote(prop.quote));
    const same = doc.proposals.find(
      (x) => x.status === 'open' && normalize(cleanQuote(x.quote)) === quote && normalize(x.replacement) === normalize(prop.replacement),
    );
    if (same) {
      if (!same.authors.includes(author)) {
        if (same.round === round.n) same.authors.push(author);
        else same.replies.push({ from: author, stance: 'agree', text: prop.reason, round: round.n, at: now });
      }
      continue;
    }
    doc.proposals.push({
      id: `P${doc.nextProposal++}`,
      round: round.n,
      authors: [author],
      quote: prop.quote,
      ...contextAt(index, hits[0], quote.length),
      replacement: prop.replacement,
      reason: prop.reason,
      status: 'open',
      replies: [],
    });
  }
  for (const r of answer.replies) {
    const target = doc.proposals.find((x) => x.id === r.proposal);
    if (!target || target.authors.includes(author)) continue;
    target.replies.push({ from: author, stance: r.stance, text: r.text, round: round.n, at: now });
  }
  return rejected;
}

  async startRound(threadId: string): Promise<{ round: number; done: Promise<void> }> {
    const thread = await this.mustDoc(threadId);
    const doc = thread.doc;
    if (this.router.roundRunning(threadId)) throw new RouterError('busy', 'A review round is already running.');
    const people = doc.included
      .map((id) => thread.participants.find((p) => p.id === id))
      .filter((p): p is Participant => !!p);
    if (!people.length) throw new RouterError('invalid', 'Include at least one participant.');
    if (!doc.markdown.trim()) throw new RouterError('invalid', 'Write or paste a draft first.');
    const n = doc.rounds.length + 1;
    const round: Round = {
      n,
      sentAt: new Date().toISOString(),
      snapshot: doc.markdown,
      participants: people.map((p) => p.id),
      notes: Object.fromEntries(people.map((p) => [p.id, { status: 'running' } as RoundNote])),
    };
    const messages = await this.prepare(thread, people, round);
    const controller = new AbortController();
    this.router.registerRound(threadId, controller);
    this.controllers.set(threadId, controller);
    doc.rounds.push(round);
    try {
      await this.router.save(thread);
    } catch (e) {
      doc.rounds.pop();
      this.finish(threadId, people);
      throw e;
    }
    const done = Promise.all(people.map((p) => this.review(thread, p, round, messages.get(p.id)!, controller.signal)))
      .then(() => this.finish(threadId, []));
    return { round: n, done };
  }

  stopRound(threadId: string): boolean {
    const running = this.router.roundRunning(threadId);
    if (running) this.controllers.get(threadId)?.abort();
    return running;
  }

  async retryReview(threadId: string, participantId: string): Promise<{ done: Promise<void> }> {
    const thread = await this.mustDoc(threadId);
    const round = thread.doc.rounds.at(-1);
    const note = round?.notes[participantId];
    if (!round || !note || (note.status !== 'error' && note.status !== 'stopped')) {
      throw new RouterError('invalid', 'Only a failed or stopped review in the latest round can be retried.');
    }
    if (this.router.roundRunning(threadId)) throw new RouterError('busy', 'A review round is already running.');
    const p = thread.participants.find((x) => x.id === participantId);
    if (!p) throw new RouterError('not_found', 'That participant does not exist.');
    const messages = await this.prepare(thread, [p], round);
    const controller = new AbortController();
    this.router.registerRound(threadId, controller);
    this.controllers.set(threadId, controller);
    round.notes[p.id] = { status: 'running' };
    await this.router.save(thread);
    const done = this.review(thread, p, round, messages.get(p.id)!, controller.signal).then(() => this.finish(threadId, []));
    return { done };
  }

  private controllers = new Map<string, AbortController>();

  /** Reserves each participant and builds its message against the round snapshot. */
  private async prepare(thread: Thread & { doc: DocState }, people: Participant[], round: Round): Promise<Map<string, { text: string; images: ImageInput[] }>> {
    const reserved: Participant[] = [];
    for (const p of people) {
      if (!this.router.tryReserve(p.id)) {
        this.finish(thread.id, reserved);
        throw new RouterError('busy', 'A participant is still replying.');
      }
      reserved.push(p);
    }
    try {
      const { blocks, images } = await this.router.renderAttachments(thread.id, thread.doc.briefAttachments ?? []);
      const asSent = { ...thread.doc, markdown: round.snapshot };
      return new Map(people.map((p) => [p.id, {
        text: composeRound({ doc: asSent, round: round.n, receiver: p.id, briefBlocks: blocks, since: this.lastReview(thread.doc, p.id, round.n) }),
        images,
      }]));
    } catch (e) {
      this.finish(thread.id, reserved);
      throw e;
    }
  }

  private lastReview(doc: DocState, participantId: string, before: number): string | undefined {
    return [...doc.rounds].reverse().find((r) => r.n < before && r.participants.includes(participantId))?.sentAt;
  }

  private async review(thread: Thread & { doc: DocState }, p: Participant, round: Round, message: { text: string; images: ImageInput[] }, signal: AbortSignal): Promise<void> {
    const hooks = { onActivity: (text: string) => this.router.emit(thread.id, { type: 'activity', messageId: `doc:${p.id}`, text }) };
    const known = new Set(thread.doc.proposals.filter((x) => x.status === 'open').map((x) => x.id));
    const note: RoundNote = { status: 'running' };
    let result = await this.router.runTurn(p, message.text, message.images, signal, hooks);
    if (result.status === 'done') {
      note.answer = result.text;
      let parsed = parseAnswer(result.text, known);
      if (!parsed.ok) {
        const repair = await this.router.runTurn(p, repairMessage(parsed.reason), [], signal, hooks);
        if (repair.status === 'done') parsed = parseAnswer(repair.text, known);
        else result = repair;
      }
      if (result.status === 'done') {
        if (parsed.ok) {
          note.status = 'done';
          note.note = parsed.value.note;
          note.rejected = ingest(thread.doc, p.id, round, parsed.value, new Date().toISOString());
        } else {
          note.status = 'error';
          note.error = { code: 'parse', message: `The answer ${parsed.reason}.` };
        }
      }
    }
    if (result.status === 'stopped') note.status = 'stopped';
    if (result.status === 'error') {
      note.status = 'error';
      note.error = result.error;
    }
    round.notes[p.id] = note;
    this.router.release(p.id);
    if (this.router.isDeleted(thread.id)) return;
    try {
      await this.router.save(thread);
    } catch (e) {
      console.error('consensus: could not save the review', e);
    }
  }

  /** Ends a round: frees any participants still reserved and forgets its controller. */
  private finish(threadId: string, people: Participant[]): void {
    for (const p of people) this.router.release(p.id);
    this.router.unregisterRound(threadId);
    this.controllers.delete(threadId);
  }

```ts
import type { Editor, JSONContent } from '@tiptap/core';

type MarkJson = { type: string; attrs?: Record<string, unknown> };

// Bold, then italic, then links. Underscore emphasis only at word edges, so snake_case stays.
const TOKEN = /\*\*(.+?)\*\*(?!\*)|(?<!\w)__(.+?)__(?!\w)|\*(.+?)\*|(?<!\w)_(.+?)_(?!\w)|\[([^\]]+)\]\(([^)\s]+)\)/;

/** A replacement's inline Markdown as TipTap text nodes with marks. */
export function inlineMarkdown(md: string, marks: MarkJson[] = []): JSONContent[] {
  const out: JSONContent[] = [];
  let rest = md;
  while (rest) {
    const m = TOKEN.exec(rest);
    if (!m) {
      out.push(textNode(rest, marks));
      break;
    }
    if (m.index) out.push(textNode(rest.slice(0, m.index), marks));
    if (m[1] !== undefined || m[2] !== undefined) out.push(...inlineMarkdown(m[1] ?? m[2], [...marks, { type: 'bold' }]));
    else if (m[3] !== undefined || m[4] !== undefined) out.push(...inlineMarkdown(m[3] ?? m[4], [...marks, { type: 'italic' }]));
    else out.push(...inlineMarkdown(m[5], [...marks, { type: 'link', attrs: { href: m[6] } }]));
    rest = rest.slice(m.index + m[0].length);
  }
  return out.filter((n) => n.text);
}

/** Replaces a range with a proposal's text, keeping the formatting the replaced words had. */
export function applyReplacement(editor: Editor, range: { from: number; to: number }, replacement: string): void {
  const inherited = (editor.state.doc.nodeAt(range.from)?.marks ?? []).map((m) => m.toJSON() as MarkJson);
  const content = inlineMarkdown(replacement.replace(/\s*\n+\s*/g, ' ')).map((n) => {
    const own = (n.marks ?? []) as MarkJson[];
    const marks = [...inherited.filter((m) => !own.some((o) => o.type === m.type)), ...own];
    return marks.length ? { ...n, marks } : { type: 'text', text: n.text };
  });
  if (content.length) editor.chain().insertContentAt(range, content).run();
  else editor.chain().deleteRange(range).run();
}

/** TipTap writes & and < as entities; the saved document keeps them as typed. */
export function cleanMarkdown(md: string): string {
  return md.replace(/&lt;/g, '<').replace(/&gt;/g, '>').replace(/&amp;/g, '&');
}

function textNode(text: string, marks: MarkJson[]): JSONContent {
  return marks.length ? { type: 'text', text, marks: marks.map((m) => ({ ...m })) } : { type: 'text', text };
}
```

```ts
import type { Node as PMNode } from '@tiptap/pm/model';
import { buildIndex, type TextIndex } from '../../shared/anchor.js';

/** The editor's plain words, each mapped to its ProseMirror position. Blocks and hard breaks read as spaces. */
export function editorIndex(doc: PMNode): TextIndex {
  const chars: { ch: string; pos: number }[] = [];
  doc.descendants((node, pos) => {
    if (node.isText) {
      const text = node.text ?? '';
      for (let i = 0; i < text.length; i++) chars.push({ ch: text[i], pos: pos + i });
    } else if (node.type.name === 'hardBreak' || node.isBlock) {
      chars.push({ ch: '\n', pos });
    }
    return true;
  });
  return buildIndex(chars);
}

```tsx
import type { Editor, Extensions } from '@tiptap/core';
import { Markdown } from '@tiptap/markdown';
import { EditorContent, useEditor } from '@tiptap/react';
import StarterKit from '@tiptap/starter-kit';
import { useEffect, useRef } from 'react';
import { cleanMarkdown } from './inlineMarkdown.js';

export function docExtensions(): Extensions {
  return [StarterKit.configure({ link: { openOnClick: false } }), Markdown];
}

type Props = {
  markdown: string;
  /** A new value reloads markdown into the editor, as after Restore. */
  revision: number;
  onChange: (markdown: string) => void;
  onReady: (editor: Editor) => void;
  onPick: (proposalId: string) => void;
  extensions?: Extensions;
};

export function DocEditor({ markdown, revision, onChange, onReady, onPick, extensions = [] }: Props) {
  const change = useRef(onChange);
  change.current = onChange;
  const editor = useEditor({
    extensions: [...docExtensions(), ...extensions],
    content: markdown,
    contentType: 'markdown',
    onUpdate: ({ editor: ed }) => change.current(cleanMarkdown(ed.getMarkdown())),
  });

  useEffect(() => {
    if (editor) onReady(editor);
    // onReady is called once per editor instance.
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [editor]);

  const loaded = useRef(revision);
  useEffect(() => {
    if (!editor || loaded.current === revision) return;
    loaded.current = revision;
    editor.commands.setContent(markdown, { contentType: 'markdown', emitUpdate: false });
  }, [editor, revision, markdown]);

  return (
    <div
      className="doc-editor"
      onClick={(e) => {
        const id = (e.target as HTMLElement).closest<HTMLElement>('[data-proposal]')?.dataset.proposal;
        if (id) onPick(id);
      }}
    >
      <EditorContent editor={editor} />
    </div>
  );
}

import { locate, toSource, type TextIndex } from '../../shared/anchor.js';
import { groupOverlaps, isYourCall } from '../../shared/proposals.js';
import type { Proposal } from '../../shared/types.js';

export type Placed = { proposal: Proposal; from: number; to: number };
export type Group = { key: string; options: Placed[]; yourCall: boolean };

/** Anchors open proposals against the live text. Overlapping ones form groups; ones whose text is gone are out of date. */
export function placeProposals(proposals: Proposal[], index: TextIndex): { groups: Group[]; stale: Proposal[] } {
  const placed = new Map<string, Placed>();
  const ranges: { id: string; start: number; end: number }[] = [];
  const stale: Proposal[] = [];
  for (const p of proposals) {
    if (p.status !== 'open') continue;
    const at = locate(index, p);
    if (!at) {
      stale.push(p);
      continue;
    }
    placed.set(p.id, { proposal: p, ...toSource(index, at) });
    ranges.push({ id: p.id, ...at });
  }
  const groups = groupOverlaps(ranges).map((ids) => {
    const options = ids.map((id) => placed.get(id)!);
    return { key: ids[0], options, yourCall: isYourCall(options.map((o) => o.proposal)) };
  });
  return { groups, stale };
}

/** The option a group shows inline: the one the user picked, else the first. */
export function shownOption(group: Group, picked: Set<string>): Placed {
  return group.options.find((o) => picked.has(o.proposal.id)) ?? group.options[0];
}

  addProseMirrorPlugins() {

      new Plugin<DecorationSet>({
        key,
        state: {
          init: () => DecorationSet.empty,
          apply: (tr, set) => (tr.getMeta(key) as DecorationSet | undefined) ?? set.map(tr.mapping, tr.doc),

      }),
    ];

export function showProposals(editor: Editor, shown: Shown[]): void {
  const tr = editor.state.tr.setMeta(key, build(editor.state.doc, shown)).setMeta('addToHistory', false);
  editor.view.dispatch(tr);
}

function build(doc: PMNode, shown: Shown[]): DecorationSet {
  const decorations: Decoration[] = [];
  for (const s of shown) {

          el.textContent = s.replacement;
          return el;
        }, { side: 1, key: `${s.id}:${s.focused}:${s.replacement}` }),

/**
 * Tops for margin cards so none overlap. Cards keep their text order; the focused card sits level with its
 * text, earlier cards move up and later ones down. If that would push a card above 0, everything shifts down.
 */
export function stackCards(items: { id: string; top: number; height: number }[], focused?: string, gap = 8): Record<string, number> {
  const sorted = [...items].sort((a, b) => a.top - b.top || a.id.localeCompare(b.id));
  const tops: Record<string, number> = {};
  const k = focused ? sorted.findIndex((i) => i.id === focused) : -1;
  const from = k >= 0 ? k : 0;
  let y = -Infinity;
  for (let i = from; i < sorted.length; i++) {
    const t = Math.max(sorted[i].top, y);
    tops[sorted[i].id] = t;
    y = t + sorted[i].height + gap;
  }
  let bottom = k >= 0 ? tops[sorted[k].id] - gap : Infinity;
  for (let i = from - 1; i >= 0; i--) {
    const t = Math.min(sorted[i].top, bottom - sorted[i].height);
    tops[sorted[i].id] = t;
    bottom = t - gap;
  }
  const min = Math.min(0, ...Object.values(tops));
  if (min < 0) for (const id of Object.keys(tops)) tops[id] -= min;
  return tops;
}

            e.preventDefault();
            send();
          }
        }}
      />
      {error && <span className="error-inline">{error}</span>}

  );

import { useLayoutEffect, useRef, useState, type ReactNode } from 'react';
import { stackCards } from './marginLayout.js';

type Item = { key: string; anchor: number; node: ReactNode };
type Props = { header: ReactNode; footer: ReactNode; items: Item[]; focused?: string; topOf: (pos: number) => number; version: number };

/** Notes pinned on top, then one card per proposal level with its text, then the resolved line. */
export function Margin({ header, footer, items, focused, topOf, version }: Props) {
  const area = useRef<HTMLDivElement>(null);
  const [tops, setTops] = useState<Record<string, number>>({});

  useLayoutEffect(() => {
    const el = area.current;
    if (!el) return;
    const areaTop = el.getBoundingClientRect().top;
    const measured = items.map((i) => ({
      id: i.key,
      top: topOf(i.anchor) - areaTop,
      height: (el.querySelector(`[data-card="${CSS.escape(i.key)}"]`) as HTMLElement | null)?.offsetHeight ?? 0,
    }));
    const next = stackCards(measured, focused);
    setTops((prev) => (JSON.stringify(prev) === JSON.stringify(next) ? prev : next));
  });

  const bottom = Math.max(0, ...items.map((i) => (tops[i.key] ?? 0) + 200));
  return (
    <aside className="margin">
      <div className="notes">{header}</div>
      <div className="cards" ref={area} style={{ minHeight: bottom }} data-version={version}>
        {items.map((i) => (
          <div key={i.key} data-card={i.key} className="card-slot" style={{ top: tops[i.key] ?? 0 }}>
            {i.node}
          </div>
        ))}
      </div>
      {footer}
    </aside>
  );
}

import { useEffect, useRef, useState } from 'react';
import { participantLabel } from '../../shared/labels.js';
import type { ModelOption, ProviderDefaults, ProviderId, Thread } from '../../shared/types.js';
import { api } from '../api.js';

type Props = {
  thread: Thread;
  models: Record<ProviderId, ModelOption[]>;
  defaults: Record<ProviderId, ProviderDefaults>;
  activity: Record<string, string>;
  running: boolean;
  onSend: () => void;
  onStop: () => void;
};

export function summaryText(thread: Thread): string {
  const included = thread.participants.filter((p) => thread.doc?.included.includes(p.id));
  if (!included.length) return 'Nobody included';
  const shown = included.slice(0, 3).map((p) => `✓ ${participantLabel(p, thread.participants)}`).join(' • ');
  return included.length > 3 ? `${shown} + ${included.length - 3} more` : shown;
}

export function ReviewBar({ thread, models, defaults, activity, running, onSend, onStop }: Props) {
  const [open, setOpen] = useState(false);
  const [adding, setAdding] = useState(false);
  const [error, setError] = useState<string>();
  const wrap = useRef<HTMLDivElement>(null);
  const included = new Set(thread.doc?.included ?? []);
  const latest = thread.doc?.rounds.at(-1);
  const busy = (id: string) => latest?.notes[id]?.status === 'running';

  useEffect(() => {
    if (!open) return;
    const onDown = (e: MouseEvent) => {
      if (!wrap.current?.contains(e.target as Node)) close();
    };
    const onKey = (e: KeyboardEvent) => {
      if (e.key === 'Escape') close();
    };
    document.addEventListener('mousedown', onDown);
    document.addEventListener('keydown', onKey);
    return () => {
      document.removeEventListener('mousedown', onDown);
      document.removeEventListener('keydown', onKey);
    };
  }, [open]);

  const close = () => {
    setOpen(false);
    setAdding(false);
    setError(undefined);
  };
  const act = (fn: () => Promise<unknown>) => fn().catch((e: Error) => setError(e.message));

  return (
    <div className="review-bar" ref={wrap}>
      <span className="review-label">Ask for review:</span>
      <button className="review-summary" onClick={() => (open ? close() : setOpen(true))}>
        {summaryText(thread)} ▾
      </button>
      {running && (
        <span className="review-activity">
          {thread.participants.filter((p) => busy(p.id)).map((p) => (
            <span key={p.id} className="spinner-line"><span className="spinner" /> {activity[`doc:${p.id}`] ?? participantLabel(p, thread.participants)}</span>
          ))}
        </span>
      )}
      <button className="review-send" disabled={!running && !included.size} onClick={running ? onStop : onSend}>
        {running ? 'Stop' : 'Send'}
      </button>
      {open && (
        <div className="chip-menu review-menu">
          {thread.participants.map((p) => (
            <div key={p.id} className={included.has(p.id) ? 'review-row included' : 'review-row'}>
              <button className="review-name" onClick={() => act(() => api.setIncluded(thread.id, p.id, !included.has(p.id)))}>
                <span className="check">{included.has(p.id) ? '✓' : ''}</span>
                <span className={`dot ${p.provider}`} /> {participantLabel(p, thread.participants)}
                {busy(p.id) && <span className="spinner" />}

              <button className="ghost review-remove" title="Remove from this thread" onClick={() => act(() => api.removeParticipant(thread.id, p.id))}>×</button>

          ))}
          {adding ? (

              defaults={defaults}
              submitLabel="Add"

          )}
          {error && <p className="error-inline">{error}</p>}
        </div>
      )}
    </div>
  );
}

```tsx
import { useState } from 'react';
import Markdown from 'react-markdown';
import type { Round } from '../../shared/types.js';

const time = (iso: string) => new Date(iso).toLocaleTimeString([], { hour: 'numeric', minute: '2-digit' });

export function HistoryMenu({ rounds, onRestore }: { rounds: Round[]; onRestore: (round: number) => Promise<void> }) {
  const [open, setOpen] = useState(false);
  const [viewing, setViewing] = useState<Round>();
  const [error, setError] = useState<string>();
  if (!rounds.length) return null;

  const restore = async (n: number) => {
    try {
      await onRestore(n);
      setViewing(undefined);
    } catch (e) {
      setError((e as Error).message);
    }
  };

  return (
    <div className="history">
      <button className="ghost icon-btn" title="History" aria-label="History" onClick={() => setOpen((o) => !o)}>
        <svg width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2" strokeLinecap="round" strokeLinejoin="round" aria-hidden="true">
          <path d="M3 12a9 9 0 1 0 3-6.7L3 8" /><path d="M3 3v5h5" /><path d="M12 7v5l3 2" />
        </svg>
      </button>
      {open && (
        <div className="history-menu">
          {[...rounds].reverse().map((r) => (
            <button key={r.n} className="menu-item" onClick={() => { setViewing(r); setOpen(false); }}>
              Round {r.n} · {time(r.sentAt)}
            </button>
          ))}
        </div>
      )}
      {viewing && (
        <div className="dialog-backdrop" onClick={() => setViewing(undefined)}>
          <div className="dialog" onClick={(e) => e.stopPropagation()}>
            <header><h2>Round {viewing.n} · {time(viewing.sentAt)}</h2><button className="ghost" onClick={() => setViewing(undefined)}>Close</button></header>
            <div className="snapshot"><Markdown>{viewing.snapshot}</Markdown></div>
            <div className="card-actions"><button onClick={() => restore(viewing.n)}>Restore</button></div>
            {error && <p className="error-inline">{error}</p>}
          </div>
        </div>
      )}
    </div>
  );
}

```tsx
import type { Editor } from '@tiptap/core';
import { useCallback, useEffect, useMemo, useRef, useState } from 'react';
import { checkFile } from '../../shared/attachmentRules.js';
import { RESOLVED } from '../../shared/proposals.js';
import type { ModelOption, ProviderDefaults, ProviderId, Thread } from '../../shared/types.js';
import { api } from '../api.js';
import { AttachmentChip } from '../components/AttachmentChip.js';
import { ThreadTitle } from '../components/ThreadTitle.js';
import { placeProposals, shownOption, type Group } from './anchoring.js';
import { copyFormatted } from './clipboard.js';
import { DocEditor } from './DocEditor.js';
import { editorIndex } from './editorIndex.js';
import { HistoryMenu } from './HistoryMenu.js';
import { applyReplacement } from './inlineMarkdown.js';
import { Margin } from './Margin.js';
import { NoteCard } from './NoteCard.js';
import { ProposalCard, StaleCard } from './ProposalCard.js';
import { ProposalHighlights, showProposals } from './proposalDecorations.js';
import { ResolvedList } from './ResolvedList.js';
import { ReviewBar } from './ReviewBar.js';

const SAVE_DELAY = 1000;
const highlights = [ProposalHighlights];

type Props = {
  thread: Thread;
  activity: Record<string, string>;
  models: Record<ProviderId, ModelOption[]>;
  defaults: Record<ProviderId, ProviderDefaults>;
};

type Pending = { markdown?: string; brief?: string };

export function DocView({ thread, activity, models, defaults }: Props) {
  const doc = thread.doc!;
  const [editor, setEditor] = useState<Editor>();
  const [version, setVersion] = useState(0);
  const [picked, setPicked] = useState<Set<string>>(new Set());
  const [focused, setFocused] = useState<string>();
  const [saveState, setSaveState] = useState<'saved' | 'saving' | 'error'>('saved');
  const [error, setError] = useState<string>();
  const [copied, setCopied] = useState(false);
  const [brief, setBrief] = useState(doc.brief);
  const pending = useRef<Pending>({});
  const timer = useRef<ReturnType<typeof setTimeout>>(undefined);
  const revision = useRef(doc.revision);
  const filePicker = useRef<HTMLInputElement>(null);

  /** Saves queued edits now. Returns false when the save failed. */
  const flush = useCallback(async (): Promise<boolean> => {
    clearTimeout(timer.current);
    const body = pending.current;
    if (body.markdown === undefined && body.brief === undefined) return true;
    pending.current = {};
    setSaveState('saving');
    try {
      await api.saveDoc(thread.id, { revision: revision.current, ...body });
      setSaveState('saved');
      return true;
    } catch (e) {
      pending.current = { ...body, ...pending.current };
      setSaveState('error');
      setError((e as Error).message);
      return false;
    }
  }, [thread.id]);

  const queue = (patch: Pending) => {
    pending.current = { ...pending.current, ...patch };
    clearTimeout(timer.current);
    timer.current = setTimeout(() => void flush(), SAVE_DELAY);
  };

  // A restore replaced the text on the server: drop edits queued against the old text.
  useEffect(() => {
    if (doc.revision === revision.current) return;
    revision.current = doc.revision;
    clearTimeout(timer.current);
    pending.current = {};
    setSaveState('saved');
    setVersion((v) => v + 1);
  }, [doc.revision]);

  // Save anything queued when leaving the doc.
  useEffect(() => () => void flush(), [flush]);

  useEffect(() => {
    if (!editor) return;
    const bump = () => setVersion((v) => v + 1);
    editor.on('update', bump);
    return () => {
      editor.off('update', bump);
    };
  }, [editor]);

  const layout = useMemo(
    () => (editor ? placeProposals(doc.proposals, editorIndex(editor.state.doc)) : { groups: [], stale: [] }),
    // version tracks edits to the editor's document.
    // eslint-disable-next-line react-hooks/exhaustive-deps
    [editor, version, doc.proposals],
  );

  const providerOf = (id: string) => thread.participants.find((p) => p.id === id)?.provider ?? 'claude';

  useEffect(() => {
    if (!editor) return;
    showProposals(editor, layout.groups.map((g) => {
      const o = shownOption(g, picked);
      return {
        id: o.proposal.id, from: o.from, to: o.to, replacement: o.proposal.replacement,
        provider: providerOf(o.proposal.authors[0]),
        focused: g.options.some((x) => x.proposal.id === focused),
      };
    }));
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [editor, layout, picked, focused]);

  const attempt = async (fn: () => Promise<unknown>) => {
    try {
      setError(undefined);
      await fn();
    } catch (e) {
      setError((e as Error).message);
    }
  };

  const accept = (g: Group, id: string, replacement: string) => attempt(async () => {
    const o = g.options.find((x) => x.proposal.id === id);
    if (!editor || !o) return;
    applyReplacement(editor, o, replacement);
    await api.updateProposal(thread.id, id, {
      status: 'accepted',
      replacement: replacement !== o.proposal.replacement ? replacement : undefined,
      notChosen: g.options.filter((x) => x.proposal.id !== id).map((x) => x.proposal.id),
    });
  });

  const pick = (g: Group, id: string) =>
    setPicked((prev) => {
      const next = new Set(prev);
      for (const o of g.options) next.delete(o.proposal.id);
      next.add(id);
      return next;
    });

  const latest = doc.rounds.at(-1);
  const running = !!latest && Object.values(latest.notes).some((n) => n.status === 'running');

  const send = () => attempt(async () => {
    if (!(await flush())) return;
    await api.startRound(thread.id);
  });

  const copy = () => attempt(async () => {
    if (!editor) return;
    await copyFormatted(editor.getHTML(), editor.getText({ blockSeparator: '\n\n' }).replace(/\n{3,}/g, '\n\n'));
    setCopied(true);
    setTimeout(() => setCopied(false), 1500);
  });

  const attach = (files: File[]) => attempt(async () => {
    const ids = (doc.briefAttachments ?? []).map((a) => a.id);
    for (const file of files) {
      const problem = checkFile(file.name, file.size);
      if (problem) throw new Error(problem);
      ids.push((await api.uploadAttachment(thread.id, file)).id);
    }
    if (!(await flush())) return;
    await api.saveDoc(thread.id, { revision: revision.current, briefAttachmentIds: ids });
  });

  const detach = (id: string) => attempt(async () => {
    if (!(await flush())) return;
    await api.saveDoc(thread.id, { revision: revision.current, briefAttachmentIds: (doc.briefAttachments ?? []).map((a) => a.id).filter((x) => x !== id) });
  });

  const topOf = (pos: number) => {
    try {
      return editor ? editor.view.coordsAtPos(pos).top : 0;
    } catch {
      return 0;
    }
  };

  const reviewers = thread.participants.filter((p) => doc.rounds.some((r) => r.participants.includes(p.id)));
  const header = (
    <>
      {reviewers.map((p) => (
        <NoteCard
          key={p.id}
          participant={p}
          all={thread.participants}
          rounds={doc.rounds.filter((r) => r.participants.includes(p.id))}
          activity={activity[`doc:${p.id}`]}
          onRetry={() => attempt(() => api.retryReview(thread.id, p.id))}
        />
      ))}
      {layout.stale.map((p) => (
        <StaleCard key={p.id} proposal={p} participants={thread.participants} onDismiss={(id) => attempt(() => api.updateProposal(thread.id, id, { status: 'dismissed' }))} />
      ))}
    </>
  );
  const items = layout.groups.map((g) => {
    const shown = shownOption(g, picked);
    return {
      key: g.key,
      anchor: shown.from,
      node: (
        <ProposalCard
          group={g}
          shown={shown.proposal.id}
          participants={thread.participants}
          focused={g.options.some((x) => x.proposal.id === focused)}
          onFocus={() => setFocused(shown.proposal.id)}
          onPickOption={(id) => pick(g, id)}
          onAccept={(id, text) => accept(g, id, text)}
          onReject={(ids) => attempt(async () => {
            for (const id of ids) await api.updateProposal(thread.id, id, { status: 'rejected' });
          })}
          onReply={(id, text) => api.replyToProposal(thread.id, id, text)}
          onEditReplacement={(id, text) => attempt(() => api.updateProposal(thread.id, id, { replacement: text }))}
        />
      ),
    };
  });

  return (
    <section className="thread-view doc-view">
      <header className="thread-head">
        <ThreadTitle thread={thread} />
      </header>
      <div className="doc-scroll">
        <div className="doc-main">
          <div className="doc-tools">
            {saveState === 'error' && <span className="not-saved" title={error}>Not saved</span>}
            <HistoryMenu rounds={doc.rounds} onRestore={async (n) => {
              clearTimeout(timer.current);
              pending.current = {};
              await api.restore(thread.id, n);
            }} />
            <button className="ghost icon-btn" title="Copy" aria-label="Copy" onClick={copy}>
              {copied ? 'Copied' : (
                <svg width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2" strokeLinecap="round" strokeLinejoin="round" aria-hidden="true">
                  <rect x="9" y="9" width="12" height="12" rx="2" /><path d="M5 15V5a2 2 0 0 1 2-2h10" />
                </svg>
              )}
            </button>
          </div>
          <div className="brief">
            <textarea
              className="brief-input"
              rows={2}
              placeholder="Brief: what this is, who reads it, and any limits"
              value={brief}
              onChange={(e) => {
                setBrief(e.target.value);
                queue({ brief: e.target.value });
              }}
            />
            <button className="ghost attach" onClick={() => filePicker.current?.click()} title="Attach files to the brief" aria-label="Attach files to the brief">
              <svg width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2" strokeLinecap="round" strokeLinejoin="round" aria-hidden="true">
                <path d="m21.44 11.05-9.19 9.19a6 6 0 0 1-8.49-8.49l8.57-8.57A4 4 0 1 1 18 8.84l-8.59 8.57a2 2 0 0 1-2.83-2.83l8.49-8.48" />
              </svg>
            </button>
            <input ref={filePicker} type="file" multiple hidden onChange={(e) => {
              attach([...(e.target.files ?? [])]);
              e.target.value = '';
            }} />
            {doc.briefAttachments?.length ? (
              <div className="att-row">
                {doc.briefAttachments.map((a) => (
                  <AttachmentChip key={a.id} threadId={thread.id} name={a.name} size={a.size} attachment={a} onRemove={() => detach(a.id)} />
                ))}
              </div>
            ) : null}
          </div>
          <DocEditor
            markdown={doc.markdown}
            revision={doc.revision}
            extensions={highlights}
            onChange={(md) => queue({ markdown: md })}
            onReady={setEditor}
            onPick={setFocused}
          />
          {error && <p className="error-inline">{error}</p>}
        </div>
        <Margin
          header={header}
          footer={<ResolvedList proposals={doc.proposals.filter((p) => RESOLVED.includes(p.status))} participants={thread.participants} />}
          items={items}
          focused={layout.groups.find((g) => g.options.some((x) => x.proposal.id === focused))?.key}
          topOf={topOf}
          version={version + doc.proposals.length}
        />
      </div>
      <ReviewBar
        thread={thread}
        models={models}
        defaults={defaults}
        activity={activity}
        running={running}
        onSend={send}
        onStop={() => attempt(() => api.stopRound(thread.id))}
      />
    </section>
  );
}
